# Hello World Plugin Example

This example shows how to define a plugin and add it to an instance. We encourage Open MCT plugins to be published as npm packages or github repositories as this makes them easier to share and distribute, as in the case of npm packages provides pre-compiled code which speeds up builds.

## Installation
To install the hello world plugin in an Open MCT instance using the build tool:

```bash
 mct plugins add file:./recipes/examples/hello-world
```
